Este repositório apresenta uma implementação prática do padrão de Arquitetura em Camadas utilizando a linguagem Python.
O projeto tem como objetivo demonstrar a organização de um sistema de software em camadas independentes, promovendo a separação de responsabilidades, a modularidade, a reutilização de código e a facilidade de manutenção.
A implementação busca evidenciar como a divisão entre as camadas de apresentação, lógica de negócio e acesso a dados contribui para o desenvolvimento de aplicações mais organizadas, escaláveis e de fácil evolução.
